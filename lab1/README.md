# ЛР №1 — проектирование цифрового устройства на ПЛИС Altera (вариант 5)

Плата DE1, ПЛИС Cyclone II EP2C20F484C7, Quartus II 13.0 SP1 Web Edition.

Вариант 5: последовательность y = 1, 2, 3, 3, 2, 2, 1, 1; счётчик обратного хода;
вход C — вывод C7; входы D[2..0] — тумблеры SW9..SW7; выходы Y[2..0] — светодиоды LEDG7, LEDG6, LEDG1.

| Каталог | Содержимое |
|---|---|
| `src/` | схема `lab1.bdf`, модули `cnt_down.v` (обратный счётчик), `rsp.v` (дешифратор y), символы, проект `.qpf/.qsf`, стимулы `lab1.vwf` |
| `constraints/` | временные ограничения `lab1.sdc` |
| `reports/` | отчёты Analysis & Synthesis, Fitter и TimeQuest |
| `bitstream/` | файл конфигурации `lab1.sof` |

Результаты: 3 логических элемента, 7 выводов, максимальная задержка D→Y 9,835 нс (ограничение 20 нс, slack 10,165 нс).
